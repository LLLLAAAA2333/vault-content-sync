# Vault Content Sync 0.4.1

首个 GitHub Release，面向 Obsidian 桌面端 1.14.4 及更新版本。

**这是实验性只读 WebDAV 预览版本。** 可以核验本地和远端内容、检查冲突；外部服务的上传、下载、合并应用及恢复仍然禁用。写入与恢复仅在本机隔离模拟服务中开放。尚未提交或获准进入 Obsidian 社区插件目录。

## 本版变化

- 名称与插件 ID 统一为 Vault Content Sync / `vault-content-sync`。
- 排除宿主实际配置目录，包括自定义目录，防止配置被当作笔记扫描或传输。
- 在保存前拒绝带凭据或查询参数的 URL，密码仅保留在当前会话。
- 简化命令和设置页标题，补齐使用、数据范围和兼容性说明。
- 将所需许可证内嵌到 main.js，增加发布附件检查和版本兼容映射。

行级三方合并、updated 仅本机保留和 format 2 状态规则保持不变。

## 验证

130 项单元测试、2 项工具故障测试、构建/类型/模块边界与发布附件检查、双设备模拟及隔离 Obsidian 合并与重启恢复。测试只使用合成库与本机模拟服务，未访问真实库或真实 WebDAV。

## 下载与试用

将同一版本的 `main.js`、`manifest.json`、`styles.css` 放入**隔离测试库**的 `<配置目录>/plugins/vault-content-sync/`，或解压 ZIP 后放入对应位置。默认配置目录是 `.obsidian`。请勿将其作为已开放真实同步的版本安装到日常笔记库。

配置自己的 HTTPS WebDAV 文件夹地址后手动预览，用户名和密码分别填写；不要把凭据或令牌放进 URL。没有 Vault Content Sync 账号要求或付费功能。

附件提供 SHA-256 清单和许可证。发布前检查范围及仍待官方判断的事项见仓库 `docs/RELEASE_REVIEW.md`。
