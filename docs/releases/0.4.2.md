# Vault Content Sync 0.4.2

This patch addresses the actionable findings in the community scorecard for 0.4.1. External WebDAV remains read-only; no automatic sync or real-service writes are enabled.

- Validate saved settings, checkpoints, rejected errors and stream chunks before use. Preserve format 2 compatibility and exact content.
- Make settings searchable using Obsidian's declarative API; keep endpoint validation and session-only passwords.
- Use explicit Node timers for HTTP request deadlines, independent of popout windows.
- Add English documentation, retain Chinese instructions, update the public listing status and disclose filesystem/base64 behavior.
- Include a complete [35-item audit](https://github.com/LLLLAAAA2333/vault-content-sync/blob/main/docs/SCORECARD_REVIEW.md) and a contributing guide.
- Attach only the three Obsidian install files. Applicable licenses remain embedded in main.js. A manual GitHub Actions build attests the install files; local isolated-tested bytes are compared before publication.

Validation: 150 unit tests, 2 tool fault tests, build/type/module/release checks, two-device simulation and isolated macOS Obsidian 1.14.4 passed. The official recommended lint has one explained warning for the extra default `.obsidian` exclusion. Direct filesystem capability is retained for byte-preserving recovery and disclosed. The actual configuration directory is also excluded using Vault.configDir.

Minimum Obsidian: 1.14.4, desktop only. No real Note vault installation or real WebDAV access was performed. Community rescanning may take time; this release does not assert a zero-warning scorecard or separate human policy approval.
