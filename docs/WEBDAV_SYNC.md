# 真实 WebDAV 同步（未发布开发版）

当前构建在连接验证通过后支持上传、下载、传播删除、采用本地/远端、普通 Markdown 三方合并和中断恢复。发布版 0.5.0 仍仅提供外部只读预览。同步操作需手动确认。

## 使用

1. 在隔离测试库填写 WebDAV 文件夹地址、用户名与密码。外部地址要求 HTTPS；本机回环允许 HTTP。
2. “测试连接”仍只检查目录可读性。“验证并开启同步”会另外确认测试地址，在该地址下新建 `.vault-content-sync-check-<随机标识>/`，只操作合成文件，不扫描或修改已有笔记。
3. 验证独占目录锁、无令牌写入被拒绝、编码路径、强 ETag、重复新建/旧版本覆盖/旧版本删除被拒绝、上传中断保留原内容，以及锁可释放重取。测试目录保留且在本地和远端均排除同步。
4. 通过后本次连接显示“可同步”。点击“核验内容”，检查差异，再确认“同步全部”或文件菜单中的“同步此文件”。确认窗口显示上传、下载和删除数量。
5. 无差异时可用“确认一致版本”建立共同基线。两端都变更的文件保留在冲突组；文件菜单支持采用本地、采用远端和合并文本。重叠编辑不写出合并正文，需要选择一端或手动编辑后重试。
6. “更多操作 → 恢复未完成操作”列出待恢复文件并另行确认。普通/单文件同步不会顺带恢复其他文件。

验证结果仅驻留内存，绑定规范化地址、用户名和密码；不可由保存的 JSON 恢复。修改连接/凭据或卸载、重启插件会撤销，迟到的旧验证不能重新开放写入。核验和内容比较仍不创建本地同步状态。

## 写入机制与限制

每次执行、应用冲突、恢复都先获得远端根目录的独占 `Depth: infinity` 写入锁，再重读内容并核验原始哈希。新建使用 `If-None-Match: *`，覆盖/删除使用强 `If-Match`；修改请求同时携带指向锁目录的 tagged `If`。锁保护子目录创建及同一远端树的其他客户端写入。失败不降级成无条件覆盖。

请求有限期 600 秒的锁，仅接受 150–600 秒的有限租约；每次写入保留完整 120 秒请求期限和额外余量。临近过期时停止，不让新传输跨越租约期限。不自动续租；较长任务可在重新核验/恢复后继续。正常结束释放锁；进程崩溃时等待服务端租约过期。释放失败会报告，原始传输失败不会被清理错误掩盖。

Apache 刚写入的文件可能暂时返回弱 ETag。持锁时最多等待 3 秒并重读核验原始内容，直到服务器返回强 ETag；不擅自把弱标签当强标签。目录 PROPFIND 使用末尾斜杠，不跟随服务器重定向。服务器返回 207 多状态的锁拒绝响应也参与验证。

所有原始版本和恢复目标仍保存在本机 `.plain-sync/`，状态格式保持 2。Markdown 顶层 `updated` 仍本机保留。读取失败不是删除，缺少共同版本时不推断删除或自动合并不同内容。目录锁不能约束绕过 WebDAV 直接修改服务器磁盘的程序；验证结果仅证明测试时观察到的行为，不保证所有服务器配置或未来状态。不同服务器必须分别通过验证，不支持所需锁/强 ETag/条件请求的服务仍只能预览。

## 独立验证

- `pnpm check`：格式、类型、社区 lint、构建与模块边界。
- `pnpm test`：纯计算、同步、恢复、认证、凭据和故障测试。
- `pnpm test:webdav`：独立 Apache mod_dav_fs + Basic 认证，验证实际协议、两个合成客户端、双向传输、合并与取舍、锁竞争、恢复及删除。
- `pnpm e2e`：原有隔离 Obsidian 全流程回归。
- `pnpm e2e:webdav`：真实 Apache 与独立 Obsidian 的验证开启、上传、下载、冲突处理和主题截图。

Apache 工具默认使用 Homebrew 的 httpd；可用 `PLAIN_HTTPD` 和 `PLAIN_HTTPD_MODULES` 指定已安装的实现路径。配置、文档根目录、认证文件、客户端和 Obsidian profile 均位于本项目新建的 `runtime/apache-*` 下；只监听回环地址，退出后停止进程，不注册后台服务。证据放在被 Git 排除的 `artifacts/`。本轮没有使用日常笔记、真实凭据或外部服务器。
