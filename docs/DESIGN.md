# 设计与边界

单个桌面插件。入口仅注册设置和命令，不自动访问网络。`src/sync` 不导入界面；`src/ui` 只依赖同步接口和 Obsidian 宿主 API；`src/merge` 是不访问磁盘与网络的纯算法。构建后通过 `tools/check-boundaries.mjs` 检查实际模块图。

## 内容与同步

当前开发版普通刷新采用会话级增量核验，首次与手动完整核验读取两端全部内容，受控并发为 2；详见下方增量核验契约。所有扩展名参与；排除 `.obsidian`、`.claudian`、`.git`、`.sync_state.json`、`.sync_trash`、`.DS_Store`、`.plain-sync`、`.trash` 和符号链接；同时按宿主 `Vault.configDir` 排除实际配置目录（含自定义目录），不读取或传输其中的内容。任何读取或列表失败均视为未知，不解释成文件缺失。

原始 SHA-256 用于写入前核验与恢复。Markdown 另计算共享表示 SHA-256，仅排除开头 YAML 中顶层、精确名为 `updated` 的属性。上传共享表示；下载、采用远端和合并保留原有本机 `updated`，原本没有则保持没有。`doneTime`、`area`、嵌套 `updated`、正文及其他类型文件照常比较。

只缓冲最多 256 KiB 的 Markdown 文件头，正文与附件流式读取。YAML 解析通过 AST 源范围移除字段，避免重新格式化其他属性；支持 BOM、CRLF、引号键和多行值。重复键、无效或无闭合 YAML、锚点/别名、含 updated 的顶层 flow map、缩进/显式 updated 键及超限头部保守停止。移除属性后只剩空白的 YAML 包装不参与共享内容。

没有共同基线时：共享内容相同则一致，单侧存在按导入处理，同路径不同共享内容为冲突。后续比较共同基线、本地、远端；不依据时间戳决定覆盖方向。路径大小写、Unicode 或文件/目录冲突保守阻止。

## 文本合并（0.4.1）

完整行为见 [MERGE_CONTRACT.md](MERGE_CONTRACT.md)。模块用精确保留终止符的行片段、整数行 ID、相对共同版本的半开改动区间和带状态标签的结果。无磁盘、网络、YAML 或同步状态依赖。`@jest/diff-sequences` 只负责 LCS；区间定位、定位可信度检查、重叠判定、来源标注和组装由本项目实现。

相邻非空区间可合并；插入与替换/删除边界相接则冲突。相同区间的相同改动只保留一次。重复行删增和移动等无法通过保守定位检查的情况停止，不选择某个偶然匹配。失败结果只有冲突区域或停止原因，没有待写入正文。换行、BOM、末行终止状态逐字保留；同步入口显式保留 UTF-8 BOM，不统一转换换行。

所有步骤共用输入总量、行数和工作预算，调用方只能降低上限。内存采用总字符与总行数量结构性约束，不承诺 JS RSS 精确上限。同步层仍限制每份原始文件 1 MiB、检查有效 UTF-8/无 NUL、校验原始哈希并复核执行前变化。`updated` 与 format 2 保持不变。

## 写入与恢复

远端新建需要原子 `If-None-Match: *`，覆盖和删除需要强 ETag 条件请求。生产能力未知，外部服务写入禁用；只允许显式选择的本机模拟服务写入。能力探测只写入指定测试父目录下新建的合成目录，不属于 dry run。

修改前归档两端原始内容、共享版本和保留本机属性的目标版本，再落盘意图。`.plain-sync/versions/` 按哈希保存内容，`.plain-sync/displaced/` 保留原 inode；编号检查点保存基线与未完成操作，不自动清理。

本地覆盖先移走原 inode 并核验，再以排他链接发布新文件；迟到的编辑保留在 displaced。重启恢复先读取实际结果；已经完成不重传，出现更新内容则停止。基线只推进到已确认的共享内容。没有跨文件事务，也不能保证与任意外部编辑器之间的原子 compare-and-swap。

状态格式为 2，元数据目录为 `.plain-sync/`；format 1 不自动迁移。最新检查点损坏会停止，不自动回退或清空状态。状态和历史未加密，应按笔记同等保护。

## 连接检查与此前弹窗界面（2026-11-12，后续侧栏替代）

“测试连接”独立于同步引擎和文件扫描：向已配置目录发送一次 PROPFIND Depth: 0，仅请求 resourcetype；不递归、不 GET 笔记、不创建 .plain-sync，也不验证写入权限。总请求期限 15 秒、XML 响应最多 64 KiB；只接受对应同源目录的一项成功集合响应。鉴权、权限、缺失目录、跳转和非 WebDAV 响应分别提示；响应正文和凭据不进入错误文案。设置在请求途中改变时，旧结果不标记为当前连接成功。

预览参考 MDSync 截图中的紧凑操作层次，自行实现宿主原生控件。顶部显示主机/目录和只读状态，主操作为核验内容；按“需要确认 / 本地变更 / 远端变更”分组，支持路径搜索与状态筛选，最多渲染 200 行并提示缩小范围。updated 和排除说明收进展开区域。外部只读模式隐藏执行、恢复和冲突应用按钮。比较文本三列展示，窄窗改成纵排。扫描回调只报告当前本地/远端阶段的完成文件数和读取字节，列表阶段不显示伪造百分比。

视觉沿用 Obsidian 主题变量：正文 font-ui-small、辅助 font-ui-smaller、标题 font-ui-large，interactive-accent 用于主操作、标题图标、进度与键盘焦点；边框 background-modifier-border、次级文字 text-muted、错误 text-error。间距使用 size-4-1/2/3/4/6，主预览宽度上限 760px、比较窗口上限 1100px，600px 以下调整工具条与比较列。保留键盘焦点和宿主明暗主题，不引入前端框架、图片素材或上游 UI 代码。

## 当前精简界面（0.5.0，2026-11-12）

沿用 Obsidian 原生主题与控件，参考 VS Code / Zed 的“侧栏列文件，主编辑区显示差异”分工，不复制其源码。侧栏标题行放刷新、筛选和更多图标；下一行仅显示目录短名与只读状态，完整地址在提示及设置中。连接测试、updated 和排除规则集中在设置页。筛选默认收起；文件按冲突、未核实、本地/远端变更分组，每行显示名称、路径和状态，最多显示 200 项。操作图标在悬停、键盘聚焦或快速预览选中时可见，触屏持续可见；也支持右键和 Shift+F10 菜单。未核实行可展开原因。摘要合为一行，扫描显示阶段进度，写入操作仍只在本机模拟模式出现。

点击文件名打开/复用主编辑区的 vault-content-sync-comparison ItemView。比较是只读的两端共享文本，不是可编辑的合并结果。相同文本行保持对齐，变化以背景和 +/− 符号标记；行号对应各端共享文本。无共同版本明确说明不能定位三方冲突，双端差异高亮不代表已证明冲突行。“原文与共同版本”按需创建完整只读文本框，此处原文指已读取的共享文本，已排除本机 updated。缺失、二进制或超过引擎 1 MiB 读取限制的文本说明不可用。

纯展示函数 compareLines 使用 @jest/diff-sequences 对精确保留换行的行做 LCS 对齐，不参与合并决策和写入。两端合计最多 500,000 UTF-16 单位、2,000 行、200,000 次相等比较；分别限制缓冲量、DOM 行数和匹配工作，整个显示任务共用。超过任一上限则不返回部分行结果，改用完整已读取文本框，明确停止高亮。LF/CRLF 和末尾换行差异会被识别，末行无换行有文字标识；视觉代码行隐藏终止符，原文框保留完整内容。

侧栏眼睛图标或文件菜单提供默认收起的快速预览，继续使用上一阶段的精确冲突投影与 8 区域、40 行、8,000 UTF-16 单位上限。刷新/写操作使比较与片段失效，切换文件/关闭/连接变化丢弃旧响应；异步完成不重新聚焦编辑区。比较内容与路径不写入 ItemView 的持久状态，恢复标签页仅提示重新选文件、不自动联网。写入确认仍为原生 Modal；updated、合并契约、format 2 与外部只读边界不变。

布局采用侧栏 8px 内边距/区块间距、30px 最小文件行和 26px 图标按钮，主比较区 16px 内边距。字体沿用 font-ui-small/smaller 与 font-monospace；边框 background-modifier-border，辅助文字 text-muted，错误 text-error，差异底色由 text-error/text-success 混合 12%，焦点 interactive-accent。比较区容器宽度 480px 以下压缩行号间距、原文列改为纵排；双端行比较保持配对。无需新增框架或图片素材。


## 密码与认证（2026-11-14，未发布工作区）

2026-11-15 审查修订：保存密码先创建新的临时密钥引用，再保存配置；成功后才提交内存状态并清除旧自有值，失败则保留原设置及旧值。关闭记住或主动清空同样先提交无引用配置。连接与凭据保存共用串行队列，保存期间拒绝新核验；后续输入的会话草稿不被较早保存完成覆盖。设置项保存失败回显原配置和明确错误。密码脏状态随设置页保留，失焦及关闭时提交；无效 URL 草稿关闭或重绘后不阻塞已保存地址。宿主 ToggleComponent.setValue 会触发 onChange，程序回填使用同步回调隔离，防止重复保存。

恢复仅将已证明的版本/内容不变量冲突标为 blocked；认证、传输和其他未分类错误向上传播，保留 pending 供修复后重试。执行/核验开始即丢弃旧预览；比较页认证失败向侧栏传播。确认弹窗返回后再次核对预览身份，连接失效的旧确认不执行。文件/目录冲突向子路径传播。WebDAV 根路径和 href 按解码后的安全路径段比较，允许等价百分号编码大小写差异，拒绝编码分隔符、控制字符和越界路径。上述更改不改变 format 2、updated 或外部只读策略。

界面仅提供一个 type=password 输入框及“记住密码”开关，默认关闭；阻止 copy/cut 事件，不提供显示或复制按钮。输入保存在内存，开启开关将其交给宿主 SecretStorage；修改已记住的值时失焦保存。内部自动生成 vault-content-sync-UUID 引用，不要求用户管理密钥名称。切回本次使用会保留当前内存值、清除配置引用，并在存储可用时将插件自有密钥值清空；存储不可用时也能切回本次使用，不删除其他共享密钥。

配置仅允许 URL、用户名、passwordMode、secretName 和 credentialScope，不接受明文 password。保存请求串行化，避免快速切换时旧配置覆盖新配置。凭据绑定到规范目录 URL 与用户名；变更连接会失效会话和保存引用。密钥每次使用时读取，支持外部轮换/删除；临时编辑值优先用于当前会话，未输入值不会悄悄回退旧密码。

使用 Obsidian 1.14.4 宿主的 isEncryptionAvailable 能力探测，只有明确返回 true 才使用持久化密钥存储。该探测在当前 SDK 类型中尚未声明，代码以运行时结构检查封装；缺失或抛错时只允许会话值，不自建加密/明文后备方案。SecretStorage.setSecret/getSecret 为公开 API。宿主加密依赖系统服务，不能防范其他已启用插件或已控制应用的程序。依据：官方 [SecretStorage 指南](https://docs.obsidian.md/plugins/guides/secret-storage)与[桌面 1.11.5 加密说明](https://obsidian.md/changelog/2026-01-20-desktop-v1.11.5/)。

有用户名却无密码时在创建连接前抛 AuthenticationError，不扫描文件或发网络请求；匿名服务（无用户名）仍可用。WebDAV HTTP 401 转为不含凭据/响应正文的同类错误；scan 等待已开始的并发读取收尾，停止继续排队，并向调用者抛出，不返回半成品计划。侧栏丢弃旧预览并显示一条认证消息；密钥错误、连接变更也失效比较内容。非认证类读取错误仍保持原有 incomplete/unknown 和禁止执行保护，不能把失败当成缺失。状态 format 2、updated、纯合并模块和外部只读策略不变。

## 增量核验契约（2026-11-15，未发布开发构建）

普通刷新由 host 显式选择 incremental；引擎 API 默认仍为 full，保持现有工具/调用方保守语义。侧栏“更多操作”与命令面板提供“完整核验所有文件”。完整核验清空旧缓存，成功结果可用于下一次增量刷新。刷新不自动执行同步，也不写入缓存或共同基线。

缓存仅保存本次加载期间的文件原始/共享哈希、大小、版本；不保存正文、不跨进程持久化，不改变 format 2。作用域包括本地根目录、远端地址/用户名身份、两端排除规则。连接/密码变化（含外部密钥值轮换）、插件卸载，以及执行/恢复/冲突应用会使缓存失效。每次任务具有代次，较早或已失效任务不能重新提交缓存。两端扫描都成功才提交新的完整缓存；列表/文件错误或认证异常清空该代缓存，不用旧结果掩盖失败。移除和排除的路径不会留在下一份缓存。

本地使用 bigint stat 的设备、inode、大小、mtimeNs、ctimeNs、birthtimeNs 和 mode；读取前后检查打开文件的元信息一致，扫描新读取完成后检查路径仍指向该版本。复用时重新检查路径和符号链接约束。相同大小及恢复旧 mtime 的普通编辑仍会通过 ctime/inode 变化被发现。元信息相同不构成跨任意文件系统的数学内容证明，时间精度较低或异常文件系统可手动完整核验；Windows/Linux 实机尚未验证。

远端每次重新列目录，并对有已核验强 ETag 的路径发送 If-None-Match 条件 GET，不直接信任 PROPFIND 中的标签。只在 304 响应也包含完全相同的强 ETag 时复用原始/共享哈希；因为 If-None-Match 使用弱比较，弱/缺失/不同响应标签需无条件重读。200 读取新正文；服务器忽略条件并返回 200 时仍完整读取；其他 HTTP 错误保守停止。404（列表后消失）、403、断流等是未核实，401 直接认证失败。规范依据：[RFC 9110 条件请求](https://www.rfc-editor.org/rfc/rfc9110.html#section-13.1.2)。服务器错误地复用强标签可能漏报变化，手动完整核验可重新计算实际内容；未验证真实服务器的标签质量。

没有改变检查前提：比较内容、执行、归档和恢复使用原有无条件读取与原始哈希验证，缓存不授予写入权限。任何读取失败仍阻止执行。目录列表仍非原子快照。

缓存最多 20,000 条（两端合计），字符串预算估算 16 MiB，按每条 path/version 字符数与 256 固定字符计费；上限覆盖数千文件库并限制额外常驻内存，不承诺 JS RSS 精确值。超限丢弃整个缓存，下轮重新读取，不能影响分类正确性。核验读取字节只累计实际新读正文，复用计数按两端文件项计算。网络仍有目录请求和每文件条件请求，优化的是重复正文传输与本地内容读取。

## 2026-11-15：真实 WebDAV 写入与 Zed 式侧栏

本节更新上文的外部只读限制。真实连接先在新建、排除同步的合成目录内通过能力验证，才获得绑定地址和凭据的会话写入权限。每次写入持有有限期独占目录锁，带 tagged If 和强条件请求；连接变化、卸载或重启撤销权限。普通计划不恢复其他路径，恢复另行确认。协议、服务边界和独立验收入口见 [WEBDAV_SYNC.md](WEBDAV_SYNC.md)。

界面目标沿用用户提供的 Zed 参考：顶部“变更”和模式文字，下方差异/筛选/更多工具栏；文件区占据剩余高度并独立滚动；底部固定远端目录、核验按钮、统计和同步操作。没有差异时提示居中，没有可执行内容时禁用同步；尚未建立共同基线时提供“确认一致版本”。文件菜单支持单文件同步，冲突继续在主编辑区比较并显式取舍。恢复的确认显示待恢复路径，单文件操作不会顺带完成未确认任务。

保留 Obsidian 原生主题、图标和键盘焦点，不新增图像或字体依赖。去掉重复的橙色标题；远端目录明确标注“远端”，模式改为“仅预览 / 可同步”。没有完整历史浏览器，因此不添加 History 标签或提交消息框。设置新增“验证并开启同步”，测试连接仍为只读操作。此变更不安装到日常库。
