# 设计与边界

单个桌面插件。入口仅注册设置和命令，不自动访问网络。`src/sync` 不导入界面；`src/ui` 只依赖同步接口和 Obsidian 宿主 API；`src/merge` 是不访问磁盘与网络的纯算法。构建后通过 `tools/check-boundaries.mjs` 检查实际模块图。

## 内容与同步

每次预览完整读取两端文件，受控并发为 2。所有扩展名参与；排除 `.obsidian`、`.claudian`、`.git`、`.sync_state.json`、`.DS_Store`、`.plain-sync`、`.trash` 和符号链接；同时按宿主 `Vault.configDir` 排除实际配置目录（含自定义目录），不读取或传输其中的内容。任何读取或列表失败均视为未知，不解释成文件缺失。

原始 SHA-256 用于写入前核验与恢复。Markdown 另计算共享表示 SHA-256，仅排除开头 YAML 中顶层、精确名为 `updated` 的属性。上传共享表示；下载、采用远端和合并保留原有本机 `updated`，原本没有则保持没有。`doneTime`、`area`、嵌套 `updated`、正文及其他类型文件照常比较。

只缓冲最多 256 KiB 的 Markdown 文件头，正文与附件流式读取。YAML 解析通过 AST 源范围移除字段，避免重新格式化其他属性；支持 BOM、CRLF、引号键和多行值。重复键、无效或无闭合 YAML、锚点/别名、含 updated 的顶层 flow map、缩进/显式 updated 键及超限头部保守停止。移除属性后只剩空白的 YAML 包装不参与共享内容。

没有共同基线时：共享内容相同则一致，单侧存在按导入处理，同路径不同共享内容为冲突。后续比较共同基线、本地、远端；不依据时间戳决定覆盖方向。路径大小写、Unicode 或文件/目录冲突保守阻止。

## 文本合并（0.4.1）

完整行为见 [MERGE_CONTRACT.md](MERGE_CONTRACT.md)。模块用精确保留终止符的行片段、整数行 ID、相对共同版本的半开改动区间和带状态标签的结果。无磁盘、网络、YAML 或同步状态依赖。`@jest/diff-sequences` 只负责 LCS；区间定位、定位可信度检查、重叠判定、来源标注和组装由本项目实现。

相邻非空区间可合并；插入与替换/删除边界相接则冲突。相同区间的相同改动只保留一次。重复行删增和移动等无法通过保守定位检查的情况停止，不选择某个偶然匹配。失败结果只有冲突区域或停止原因，没有待写入正文。换行、BOM、末行终止状态逐字保留；同步入口显式保留 UTF-8 BOM，不统一转换换行。

所有步骤共用输入总量、行数和工作预算，调用方只能降低上限。内存采用总字符与总行数量结构性约束，不承诺 JS RSS 精确上限。同步层仍限制每份原始文件 1 MiB、检查有效 UTF-8/无 NUL、校验原始哈希并复核执行前变化。`updated` 与 format 2 保持不变。

## 写入与恢复

远端新建需要原子 `If-None-Match: *`，覆盖和删除需要强 ETag 条件请求。生产能力未知，外部服务写入禁用；只允许显式选择的本机模拟服务写入。能力探测只写入指定测试父目录下新建的合成目录，不属于 dry run。

修改前归档两端原始内容、共享版本和保留本机属性的目标版本，再落盘意图。`.plain-sync/versions/` 按哈希保存内容，`.plain-sync/displaced/` 保留原 inode；编号检查点保存基线与未完成操作，不自动清理。

本地覆盖先移走原 inode 并核验，再以排他链接发布新文件；迟到的编辑保留在 displaced。重启恢复先读取实际结果；已经完成不重传，出现更新内容则停止。基线只推进到已确认的共享内容。没有跨文件事务，也不能保证与任意外部编辑器之间的原子 compare-and-swap。

状态格式为 2，元数据目录为 `.plain-sync/`；format 1 不自动迁移。最新检查点损坏会停止，不自动回退或清空状态。状态和历史未加密，应按笔记同等保护。

## 连接检查与此前弹窗界面（2026-11-12，后续侧栏替代）

“测试连接”独立于同步引擎和文件扫描：向已配置目录发送一次 PROPFIND Depth: 0，仅请求 resourcetype；不递归、不 GET 笔记、不创建 .plain-sync，也不验证写入权限。总请求期限 15 秒、XML 响应最多 64 KiB；只接受对应同源目录的一项成功集合响应。鉴权、权限、缺失目录、跳转和非 WebDAV 响应分别提示；响应正文和凭据不进入错误文案。设置在请求途中改变时，旧结果不标记为当前连接成功。

预览参考 MDSync 截图中的紧凑操作层次，自行实现宿主原生控件。顶部显示主机/目录和只读状态，主操作为核验内容；按“需要确认 / 本地变更 / 远端变更”分组，支持路径搜索与状态筛选，最多渲染 200 行并提示缩小范围。updated 和排除说明收进展开区域。外部只读模式隐藏执行、恢复和冲突应用按钮。比较文本三列展示，窄窗改成纵排。扫描回调只报告当前本地/远端阶段的完成文件数和读取字节，列表阶段不显示伪造百分比。

视觉沿用 Obsidian 主题变量：正文 font-ui-small、辅助 font-ui-smaller、标题 font-ui-large，interactive-accent 用于主操作、标题图标、进度与键盘焦点；边框 background-modifier-border、次级文字 text-muted、错误 text-error。间距使用 size-4-1/2/3/4/6，主预览宽度上限 760px、比较窗口上限 1100px，600px 以下调整工具条与比较列。保留键盘焦点和宿主明暗主题，不引入前端框架、图片素材或上游 UI 代码。


## 第一版源代码管理侧栏（历史开发阶段，已由下节替代）

该阶段主界面为注册类型 vault-content-sync-changes 的原生 ItemView，通过 ensureSideLeaf 在左侧工作区打开或复用已有视图，正文编辑区保持可用。工作区恢复视图仅渲染空界面，不自动请求网络。完整比较和写入确认仍使用原生 Modal。

延续 Obsidian 主题，参考 VS Code 源代码管理的侧栏交互：标题、连接目标、手动核验按钮、进度、筛选与可折叠分组。宽度由宿主侧栏调节，单个外层纵向滚动区域；采用 12px 内容边距、10px 区块间距、7px/6px 紧凑文件行，正文 font-ui-small、辅助 font-ui-smaller，保留宿主明暗主题和可见焦点。

点击冲突文件名时才读取当前版本，并用同步引擎复核预览哈希。纯展示投影 describeConflict 使用 mergeText 的 ConflictRegion：以共同版本的半开行区间重建各端片段，不改变合并判定。行号对应移除本机 updated 后的共同文本；本地与远端文本只标侧别，不伪造原文件行号。没有共同版本时显示两端预览，缺失/二进制/过大文本、定位歧义或计算超限均说明原因；无重叠时显示可合并的分析结论，不输出待写入目标。

最多展示 8 个区域，每侧最多 40 行或 8,000 个 UTF-16 单位，避免切断 Emoji 代理对；截断和省略区域有明确提示，完整比较仍可打开。展示用 textContent，不渲染笔记 HTML。选中片段仅驻留内存，不进入工作区持久状态。切换文件、刷新或关闭使旧请求失效；连接参数变更的结果也丢弃。仅在刷新前仍聚焦冲突按钮时恢复焦点，不从正文或筛选框抢走焦点。外部只读模式不开放任何片段应用、覆盖或恢复操作。


## 当前精简界面（0.5.0，2026-11-12）

沿用 Obsidian 原生主题与控件，参考 VS Code / Zed 的“侧栏列文件，主编辑区显示差异”分工，不复制其源码。侧栏标题行放刷新、筛选和更多图标；下一行仅显示目录短名与只读状态，完整地址在提示及设置中。连接测试、updated 和排除规则集中在设置页。筛选默认收起；文件按冲突、未核实、本地/远端变更分组，每行显示名称、路径和状态，最多显示 200 项。操作图标在悬停、键盘聚焦或快速预览选中时可见，触屏持续可见；也支持右键和 Shift+F10 菜单。未核实行可展开原因。摘要合为一行，扫描显示阶段进度，写入操作仍只在本机模拟模式出现。

点击文件名打开/复用主编辑区的 vault-content-sync-comparison ItemView。比较是只读的两端共享文本，不是可编辑的合并结果。相同文本行保持对齐，变化以背景和 +/− 符号标记；行号对应各端共享文本。无共同版本明确说明不能定位三方冲突，双端差异高亮不代表已证明冲突行。“原文与共同版本”按需创建完整只读文本框，此处原文指已读取的共享文本，已排除本机 updated。缺失、二进制或超过引擎 1 MiB 读取限制的文本说明不可用。

纯展示函数 compareLines 使用 @jest/diff-sequences 对精确保留换行的行做 LCS 对齐，不参与合并决策和写入。两端合计最多 500,000 UTF-16 单位、2,000 行、200,000 次相等比较；分别限制缓冲量、DOM 行数和匹配工作，整个显示任务共用。超过任一上限则不返回部分行结果，改用完整已读取文本框，明确停止高亮。LF/CRLF 和末尾换行差异会被识别，末行无换行有文字标识；视觉代码行隐藏终止符，原文框保留完整内容。

侧栏眼睛图标或文件菜单提供默认收起的快速预览，继续使用上一阶段的精确冲突投影与 8 区域、40 行、8,000 UTF-16 单位上限。刷新/写操作使比较与片段失效，切换文件/关闭/连接变化丢弃旧响应；异步完成不重新聚焦编辑区。比较内容与路径不写入 ItemView 的持久状态，恢复标签页仅提示重新选文件、不自动联网。写入确认仍为原生 Modal；updated、合并契约、format 2 与外部只读边界不变。

布局采用侧栏 8px 内边距/区块间距、30px 最小文件行和 26px 图标按钮，主比较区 16px 内边距。字体沿用 font-ui-small/smaller 与 font-monospace；边框 background-modifier-border，辅助文字 text-muted，错误 text-error，差异底色由 text-error/text-success 混合 12%，焦点 interactive-accent。比较区容器宽度 480px 以下压缩行号间距、原文列改为纵排；双端行比较保持配对。无需新增框架或图片素材。
