# 设计与边界

单个桌面插件。入口仅注册设置和命令，不自动访问网络。`src/sync` 不导入界面；`src/ui` 只依赖同步接口和 Obsidian 宿主 API；`src/merge` 是不访问磁盘与网络的纯算法。构建后通过 `tools/check-boundaries.mjs` 检查实际模块图。

## 内容与同步

每次预览完整读取两端文件，受控并发为 2。所有扩展名参与；排除 `.obsidian`、`.claudian`、`.git`、`.sync_state.json`、`.DS_Store`、`.plain-sync`、`.trash` 和符号链接。任何读取或列表失败均视为未知，不解释成文件缺失。

原始 SHA-256 用于写入前核验与恢复。Markdown 另计算共享表示 SHA-256，仅排除开头 YAML 中顶层、精确名为 `updated` 的属性。上传共享表示；下载、采用远端和合并保留原有本机 `updated`，原本没有则保持没有。`doneTime`、`area`、嵌套 `updated`、正文及其他类型文件照常比较。

只缓冲最多 256 KiB 的 Markdown 文件头，正文与附件流式读取。YAML 解析通过 AST 源范围移除字段，避免重新格式化其他属性；支持 BOM、CRLF、引号键和多行值。重复键、无效或无闭合 YAML、锚点/别名、含 updated 的顶层 flow map、缩进/显式 updated 键及超限头部保守停止。移除属性后只剩空白的 YAML 包装不参与共享内容。

没有共同基线时：共享内容相同则一致，单侧存在按导入处理，同路径不同共享内容为冲突。后续比较共同基线、本地、远端；不依据时间戳决定覆盖方向。路径大小写、Unicode 或文件/目录冲突保守阻止。

## 文本合并（0.4.0）

完整行为见 [MERGE_CONTRACT.md](MERGE_CONTRACT.md)。模块用精确保留终止符的行片段、整数行 ID、相对共同版本的半开改动区间和带状态标签的结果。无磁盘、网络、YAML 或同步状态依赖。`@jest/diff-sequences` 只负责 LCS；区间定位、定位可信度检查、重叠判定、来源标注和组装由本项目实现。

相邻非空区间可合并；插入与替换/删除边界相接则冲突。相同区间的相同改动只保留一次。重复行删增和移动等无法通过保守定位检查的情况停止，不选择某个偶然匹配。失败结果只有冲突区域或停止原因，没有待写入正文。换行、BOM、末行终止状态逐字保留；同步入口显式保留 UTF-8 BOM，不统一转换换行。

所有步骤共用输入总量、行数和工作预算，调用方只能降低上限。内存采用总字符与总行数量结构性约束，不承诺 JS RSS 精确上限。同步层仍限制每份原始文件 1 MiB、检查有效 UTF-8/无 NUL、校验原始哈希并复核执行前变化。`updated` 与 format 2 保持不变。

## 写入与恢复

远端新建需要原子 `If-None-Match: *`，覆盖和删除需要强 ETag 条件请求。生产能力未知，外部服务写入禁用；只允许显式选择的本机模拟服务写入。能力探测只写入指定测试父目录下新建的合成目录，不属于 dry run。

修改前归档两端原始内容、共享版本和保留本机属性的目标版本，再落盘意图。`.plain-sync/versions/` 按哈希保存内容，`.plain-sync/displaced/` 保留原 inode；编号检查点保存基线与未完成操作，不自动清理。

本地覆盖先移走原 inode 并核验，再以排他链接发布新文件；迟到的编辑保留在 displaced。重启恢复先读取实际结果；已经完成不重传，出现更新内容则停止。基线只推进到已确认的共享内容。没有跨文件事务，也不能保证与任意外部编辑器之间的原子 compare-and-swap。

状态格式为 2，元数据目录为 `.plain-sync/`；format 1 不自动迁移。最新检查点损坏会停止，不自动回退或清空状态。状态和历史未加密，应按笔记同等保护。
